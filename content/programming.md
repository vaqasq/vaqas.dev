## Projects

### Docker Container Health Monitor
A go daemon that monitors my vps docker containers without using docker's SDK, stores data in a local SQLite database, and presents data via HTML.
- [View Source on GitHub](https://github.com/vaqasq/monitor.vaqas.dev)

### Custom Unix Shell
Implementing a Bash-like shell in *C* with a *REPL*, *pipelines* (*fork/exec* + *pipes*), and asynchronous child processes that uses my personal coreutil implementations.
- [View Source on GitHub](https://github.com/vaqasq/c_reimplementations)

### Self-Managed Server
I own a basic vps where I host a lot of cool stuff! These include a Blocky DNS proxy for ad blocking, a Web Server (Caddy), a lightweight VPN Protocol (Wireguard), and more!

### Gotex

- [View Source on GitHub](https://github.com/vaqasq/gotex)
