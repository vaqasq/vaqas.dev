projects

container health monitor

A Go daemon that monitors Docker containers by talking directly to the Docker Engine API over a Unix socket. Stores metrics in SQLite and serves a live dashboard at dashboard.vaqas.dev, built with React and TypeScript. The original server side rendered version is still up at monitor.vaqas.dev.

gotex

Built a Go terminal text editor using raw terminal mode to capture individual keystrokes. Implemented insert/delete/save operations, cursor movement, ANSI screen redraws, and byte-level escape-sequence parsing without a TUI library.

personal portfolio site

This site. Built with Go using net/http and html/template, fetching NASA's Astronomy Picture of the Day and caching it until midnight to avoid redundant API calls. Deployed with Docker and Caddy.
